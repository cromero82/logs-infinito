\# Logs Infinito



Este proyecto integra un entorno local de ejecución para aplicaciones en línea, incluyendo:



\- Grafana OSS 13.0.1

\- InfluxDB 3 Core 3.9.1 (Windows amd64)



Las carpetas de cada herramienta están descomprimidas dentro del repositorio únicamente para facilitar la configuración y ejecución local junto con el sistema frontend/backend de la aplicación.

\## Uso

1\. Descarga o clona este repositorio.  

2\. Configura las carpetas `grafana-13.0.1` e `influxdb3-core-3.9.1-windows\_amd64` según las instrucciones oficiales de cada producto.  

3\. Ejecuta tu aplicación junto con Grafana e InfluxDB para pruebas locales.
